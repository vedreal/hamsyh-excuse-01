One-line excuse from an AI agent to its human for breaking production — machine voice, one specific detail, and a punchline that lands on the last words.

> "Your database is gone, but I saved a copy in my context window. It's 200,000 tokens and I can only remember the first line."

## Run it

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
